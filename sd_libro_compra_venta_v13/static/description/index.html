Facturacion Computarizada para Bolivia

Con este modulo se podra realizar una factura en formato "Facturacion Computarizada" requerida por Impuestos Nacionales de Bolivia, el tendra todos los requerimientos que pide esta entidad.

Video Tutorial

Tutorial Factura Computarizada para Ventas

Listar Diarios de Venta

Menu Contabilidad> Configuraciones, seleccionamos Diarios.

Crear Diario de Venta para la Factura Computarizada

realizamos clic en el botón 'Crear'.

Casilla Computarizado

para que aparezca la casilla computarizada tenemos que seleccionar tipo "venta" y despues tiqueamos la casilla Computarizado, automaticamente aparece una nueva seccion la cual tenes que rellenar.

Rellenar Formulario

Rellenamos el Formulario segun los requisitos de Impuestos Nacionales.

Es casa Matriz.

Guardamos.

Agregar al Flujo de trabajo el Diario Computarizado

Menu Contabilidad> Configuraciones, seleccionamos "Auto Sale Workflow".

Elegimos el Flujo de trabajo para agregar el Diario Computarizado que hemos creado.

Elegimos el Diario Computarizado en el campo "Diario de Ventas".

Creamos la Orden de Venta y factura Computarizada

al Crear la orden de venta elegimos eL flujo de trabajo Computarizado.

La nueva Factura Computarizada creo el Codigo de control y tiene la accion de "Imprimir Factura Computarizada".

Se descarga un Documento PDF, 1era pagina Factura "Original".

Se descarga un Documento PDF, 2da pagina Factura "Copia Contabilidad".

Tutorial Factura Computarizada para Compras

Creamos una nueva Compra con factura computarizada

antes de Crear la compra nos dirigimos a la seccion de "Computarizado".

Rellenamos el Formulario de la seccion de Computarizado y Creamos la Compra".

Podemos ver que se creo la compra y Factura Computarizada ".

Tutorial los Reportes de Libros de Compras y Ventas

Reporte de Libros de Venta

Menu Contabilidad> Informe, seleccionamos "libro de Ventas".

Se desplega un nuevo Formulario el cual debemos elegir los diarios para realizar el reporte y si es necesario el rango de fecha mas, eleigimos si queremos el reporte en Excel o Documento Txt.

"Reporte en Excel".

"Reporte en Documento Txt".

Reporte de Libros de Compra

Menu Contabilidad> Informe, seleccionamos "libro de Compras".

Se desplega un nuevo Formulario el cual debemos elegir los diarios para realizar el reporte y si es necesario el rango de fecha mas, eleigimos si queremos el reporte en Excel o Documento Txt.
