Modulo de Agencia Despachante

Este modulo esta desarrollado para automatizar procesos de Agencias despachante de Bolivia

Caracteristicas

Orden Despacho de Importacion

Realiza un seguimiento diario del estado de su Importacion.

Notificaciones Push y Mensaje en tiempo real

Se Notifica el cambio de estado de su importacion con un mensaje al usuario.

Configuracion antes de su Instalacion en Ubuntu 18.04

Tener Instalado Google Chrome v78.0.3904.97

Comando para saber la version:
1) sudo google-chrome --version

Instalacion de Selenium

Comandos:
1) cd /opt/odoo13
2) python3 -m venv odoo-venv
3) source odoo-venv/bin/activate
4) pip3 install -U selenium
5) deactivate

Instalacion de Chromedriver v78.0.3904.70

Comandos:
1) sudo apt-get install unzip
2) wget -N http://chromedriver.storage.googleapis.com/78.0.3904.70/chromedriver_linux64.zip
3) unzip chromedriver_linux64.zip
4) chmod +x chromedriver
5) sudo mv -f chromedriver /usr/local/share/chromedriver
6) sudo ln -s /usr/local/share/chromedriver /usr/local/bin/chromedriver
7) sudo ln -s /usr/local/share/chromedriver /usr/bin/chromedriver
