Landed Cost Additional Cost Template

This module allows your inventory user to Load Additional Costs on landed cost using a cost template.


Main Features:
  • Allow your inventory user to create and manage landed cost templates for additional cost.
  • Load Cost Template button on Landed Costs Form which will allow you to load templates of additional cost.
  • Open wizard from Load Cost Template button and Load Additional Cost for Landed Cost.
  • For more details please check below screenshots and watch the video.

Menus Available:

  • Inventory
    • Configuration
      • Landed Cost Template
