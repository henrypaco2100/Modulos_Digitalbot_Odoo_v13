Setup & Configure

Generate google captcha keys.

After the successful installation of the "CAPTCHA Login LockDown" module you will have to generate the keys from google console.

Copy these generated keys for further use.

Enable Login LockDown

Please follow these steps

  1. Enable the captcha login lockdown
  2. Put your captcha secret key
  3. Put your captcha site key
  4. Set the maximum failed attempt limit

Note:
The maximum attempt value is the value after which user account will lock and for further login he must have to submit captcha.Even if he will put right email & password, once after lock down he can't login till he will not submit the captcha along with right email & password.
